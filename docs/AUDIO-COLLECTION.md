## 真实生成过程

2026-10-28，使用 CUA 创建独立 Chrome 标签页，打开 tests/audio-collection.html，点击“生成完整声景 WAV”。由该页面直接调用现有 Soundscape 的真实 Web Audio 合成图和 OfflineAudioContext，随后点击页面下载链接。没有通过 Node / CLI / Playwright / headless 控制浏览器生成本文件；未运行壁纸 GPU 技术测试。

本次实际 noiseMode 为 **continuous-worklet**，由 AudioWorklet 连续生成粉红噪声。离线时只将主音量调度与标签页前台状态隔离，音色、滤波、和声、事件声音与产品使用同一代码。每 0.25 秒传入统一阵风公式及 time/wind/water/cloud/gust 参数。场景边界使用引擎的平滑参数过渡，第一段渐入、最后约 1.25 秒渐出。短瞬态按各风格的真实合成方法，在片段内第 2 和 4.25 秒调度，以方便对比；不是随机事件密度的长期验证。

音量参数 **0.38**，未经响度归一化、增益后处理或硬削波。第一段从零平滑起音。不同风格自身响度有意保留差异，请以舒适设备音量试听。
