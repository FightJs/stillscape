# 25 · 棱镜回廊 / Prism Corridor

入口：`/experiences/prism-corridor.html`，嵌入加 `?embed=1`。

原创实时 Three.js 动能装置。26 座有倒角与厚度的八边形机械环，黑陶瓷外圈、镀铬内圈、香槟金构件、细窄发光嵌条；内外圈相向旋转。10.5 单位/秒的默认轴向位移与缓慢弯曲中心线产生连续穿越，尺度呼吸与镜头轻微游动改变遮挡关系。电紫、冰蓝、橙金连续平滑过渡。

本地 Three.js 经典脚本，程序生成环境反射，无外网素材。PMREM 反射、金属粗糙度差异、四盏近场点光和雾产生材质层次。像素比上限 1.65，共享几何与材质，远处轻微尘点仅为辅助。

接入统一 WallpaperBridge：setPlaying、setSettings(speed/power)、reset、snapshot、getState。暂停或 power=0 不推进时间并停止持续 RAF；标签隐藏取消 RAF，恢复首帧不补算时间。截帧同步 render，WebGL 初始化失败显示提示。独立模式有暂停按钮，embed 模式隐藏标题与按钮。

验证：独立内联 JavaScript 语法检查；浏览器视觉验收由统一 reviewer 执行。

第二轮视觉增强：降低白色金属反射曝光，把高饱和电紫、冰蓝、橙金嵌条移至环体正面，并按深度错开连续渐变。轻薄的低透明度加色光晕围绕嵌条；四段式节奏交替八边环、透光晶体内核、方形悬浮内机构、六边主环。保留原穿越速度及公共 UI。已看首轮真实截图；第二轮等待统一重新验收封面。
