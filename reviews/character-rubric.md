# 鲜艳动漫人物动态壁纸：独立评审标准

在实际页面及实现审查前制定。以 rubirc.md 为原标准，替换油画风景专属主体要求，不降低八维、等权及数值门槛。适用于 17-electric-idol 至 22-crimson-swordswoman 六款新增壁纸。评分不代表任何具体奖项的官方评审或获奖。

## 两层结论

1. **本轮功能验收**：逐款真实页面跨时刻观察，默认已有明显且与画面相关的动效；最大速度和强度有效；暂停冻结、恢复继续；沉浸可进入退出；返回入口有效。任一关键项失败则该款功能不通过。截图仅证明瞬间，观察记录才可支持运动结论。
2. **艺术与商用数值评审**：保留下面八维，每维 12.5%，不以功能通过代替艺术达标。完全无法感知的核心质量维度用 5.0 待验证占位，保留平均。声音未提供或未实听明示未验证，不推断优秀，也不伪造听感。

## 评分锚点与证据

0 缺失/失效；1–2 仅概念或不可用；3–4 粗糙且损伤体验；5–6 可用原型但明显欠精修；7 完成度较好但未达基线；8 达基线、仅小缺陷；9 卓越且实证充分；10 标杆级且近乎无缺陷。允许 0.1 步进。

关键视觉接缝、错误形变或无效主控制使相关维度至多 7；严重阻碍核心体验至多 4。没有与主题相关的有效动态表现时，动效至多 6。无许可证据不推断侵权，但商用完成度不可达 8。未测性能不能凭流畅观感宣称帧率稳定。代码不能替代感官观察。单一问题跨维扣分须分别说明影响。

完全无法感知的核心质量项填 5.0、标记待验证，并降低置信度；不能删除维度或重分配权重。部分验证维度根据已有证据保守评分。记录测试条件、跨时刻及交互观察、证据、未验证项、置信度和改进建议。

## 创意强化：逐款必查

本节为 2026-10-28 新增要求。先实看页面、实际操作和跨时刻观察，再按证据评分；过往报告只代表当时版本和标准，不自动变为本标准的通过结果。

1. 每款用一句话写出具体创意命题，并说明主体、世界观和动作之间的因果关系；“某种人物加星光”或单纯列举风格与颜色不算命题。
2. 每款至少有一个可辨认、与主体相关的标志性动态事件，能够观察其前奏、发生与收束；节奏应适合长期观看。交互作品可以由用户触发，需注明触发方式及待机状态。
3. 进行“替换底图测试”：若把主体换成其他不相关图像后，整套动效仍几乎完全成立，创意分上限 6.5。说明判断依据，不以代码复用本身判定失败。
4. 若变化仅由通用粒子、光环、扫光或整图缩放构成，创意分上限 7.0；颜色鲜艳、细节密集、效果数量或功能数量本身不构成创意证据。
5. 横向比较同批作品的构图、运动逻辑、材质语言和互动方式，说明每款的实质差异；若只是更换人物、配色和同一套效果，不能评为创意达标。
6. 报告逐款记录参考来源、借鉴的风格机制、原创改变、最值得记住的动态瞬间、观察时刻或操作、缺陷和置信度。参考不等于复制角色、品牌、素材或具体构图；来源许可仍需单独核验。

## 数值门槛（原标准加创意硬门槛）

A = 八维分数之和 / 8；H = 严格大于 7.5 的维度数；C = 创意惊艳分。数值通过当且仅当 **A ≥ 8.0、H ≥ 5 且 C ≥ 8.5**。7.5 不算高分项，报告未取整均分、H 和 C。存在完全未验证的核心感官项时，最多为“数值达标但验收待验证”；未达任一门槛如实为“不通过”。不能将本轮功能通过表述为最终商用验收或艺术获奖。
